# Conversation Summary Trigger

Trigger on requests like:

-   "summarize this chat"
-   "recap this conversation"
-   "give me a prompt that captures all of this"
-   "wrap this up so I can start fresh"
-   "I'm about to lose context, save this"

Also trigger on any request asking to condense:

-   "this thread"
-   "the whole conversation"
-   "everything so far"

into something portable.

## Purpose

When one of these requests is detected, produce a concise, portable
summary that preserves the important context so it can be reused in a
new chat.
